# Security Policy

## Supported Versions

Model Guardian is currently in **Phase 0 / pre-1.0** development. Security fixes
are provided for:

| Version | Supported |
| ------- | --------- |
| `main` (default branch) | :white_check_mark: |
| Most recent tagged release | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Preferred:

1. Report via **GitHub Security Advisories** ("Report a vulnerability" on the repo).

If GitHub Security Advisories are not available, contact the maintainers privately
via GitHub (e.g., by emailing a listed maintainer on their profile).

What to include:

- A clear description of the issue and its impact.
- Steps to reproduce (proof-of-concept if possible).
- Affected versions/commit hashes.
- Any suggested fix or mitigation.

What to expect:

- We aim to acknowledge receipt within **3 business days**.
- We will provide a status update once we have triaged the report and can
  confirm scope/severity.
- If accepted, we will work with you on a coordinated disclosure timeline.

Thanks for helping keep Model Guardian safe.
